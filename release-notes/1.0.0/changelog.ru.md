# KIMI KRINIK 1.0.0

2026-11-25

KIMI KRINIK 1.0.0 объединяет официальный движок Kimi Code 2.7.2 и интерфейс KIMI FORK. Расширение добавляет самостоятельный контроль контекста, надёжную отправку сообщений и интерфейс на трёх языках.

## Что нового

- Автоматическое сжатие контекста отключается, включая уже идущую операцию. Ручной `/compact` остаётся доступным.

- Контроль контекстного окна работает с настраиваемыми порогами и без KAIF. Пороговые сообщения передают работу в новый чат до переполнения окна.

- AUTO STEER немедленно отправляет дополнения в текущий ход, а OFF возвращает обычную очередь. Пачка сообщений отправляется один раз по порядку, отклонённые возвращаются на исходные места.

- Изображения, видео и сообщения без текста отображаются с кликабельными миниатюрами и существующим просмотрщиком после восстановления истории. Ручные переносы и пустые строки сохраняются.

- Запрос, которому принадлежит читаемый ответ, закрепляется сверху и раскрывается анимированным шевроном в углу. Время отправки отображается слева от пузыря пользователя.

- Пустой чат всегда показывает полный локализованный список быстрых команд, а розовый робот стоит рядом с KIMI без обрезания на узкой панели.

- Кнопка «Навык» в Control Panel открывает прокручиваемый список из двух строк с локализованными описаниями. Выбранный навык сразу уходит через Steer или встаёт в очередь при OFF.

- Sticky скрывается в самом начале чата и сворачивается при пользовательской прокрутке или смене закреплённого запроса. Сообщение Стиринга находится над единственным индикатором «Работаю…» до прихода реального ответа.

- Модель и уровень рассуждений выбираются в одном меню с поиском и избранным. MAX/XHigh сохраняется между сессиями, восстановленная сессия хранит собственный уровень.

- English, Русский и 中文 переключаются в диалоге, где активный язык стоит первым.

- Для каждого события настраиваются звук и громкость с готовыми записями на трёх языках. После «Выкл» выбор звука остаётся доступным.

- Панель управления прокручивается только при реальном переполнении. Статусы, индикатор «Работаю…» и розовый робот KIMI KRINIK работают на официальном движке. Версия и номер билда видны в Action Menu.

- История восстанавливается без пустых кадров, а запоздавшие ошибки подготовки запроса не удаляют не связанные с ними ходы. Видимый ответ остаётся в разговоре при завершении потоковой отрисовки. Внутренние служебные инструкции не отображаются как ответ агента ни в живом чате, ни при восстановлении истории.

## Проверка

Билд 25 прошёл 621 проверку, ещё одна пропущена по плану. Typecheck и lint зелёные, упаковка и статическая проверка успешны. Изолированный билд 25 подтвердил стартовый экран, локализованный выбор навыка, немедленный Steer, выбор навыка в очередь, границы sticky и подсказки ON/OFF. Билд 25 установлен на основной профиль с совпадающими хешами extension и webview; приёмка там ждёт перезапуск текущего Extension Host.

## Установка

Скачайте `kimi-code-win32-x64.vsix` и выберите **Extensions → ⋯ → Install from VSIX…**. KIMI KRINIK встаёт рядом с официальным Kimi Code и KIMI FORK, проекты и сессии сохраняются. При возврате к официальному расширению они не удаляются.
