# KIMI KRINIK 1.0.0

2026-11-27

KIMI KRINIK 1.0.0 помогает управлять длинными сессиями агента, досылать сообщения без пропажи и вовремя получать сигналы о необходимом ответе. Официальный движок Kimi Code 2.7.2 сохранён.

## Проверка

Расширение прошло 682 проверки, ещё одна пропущена по плану. Typecheck и lint зелёные. Изолированная установка подтвердила видимость чата, завершение steering, восстановление истории, звуковые настройки и диалоги с измеренными кадрами и скриншотами. Упакованы шесть платформенных VSIX и универсальный `kimi-code-universal.vsix`; статическая проверка каждого пакета успешна. Пакеты win32-x64 и universal прошли запуск в свежем Extension Host.
