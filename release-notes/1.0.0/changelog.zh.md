# KIMI KRINIK 1.0.0

2026-11-25

KIMI KRINIK 1.0.0 将官方 Kimi Code 2.7.2 引擎与 KIMI FORK 界面结合，加入独立的上下文管理、可靠的追加消息和三语言界面。

## 新功能

- 可关闭自动压缩，包括正在进行的操作。手动 `/compact` 仍可使用。

- 上下文窗口控制支持可配置阈值且无需 KAIF。阈值消息在窗口溢出前将工作交接到新聊天。

- AUTO STEER 立即发送追加消息，OFF 恢复普通队列。整批消息按顺序仅发送一次，被拒绝的消息回到原位置。

- 图片、视频和纯媒体消息提供可点击缩略图，恢复历史后使用同一查看器。手动换行和空行原样保留。

- 当前回答所属的用户请求保持置顶，通过带动画的箭头图标展开或折叠。用户气泡内显示本地化的发送时间。

- 模型与推理强度通过一个选择器设置，支持搜索和收藏。MAX/XHigh 选择会持久保存，恢复的会话保留自己的强度。

- English、Русский 和 中文 可在对话框中切换，当前语言始终排在首位。

- 每个事件可设置声音与音量，并提供三种语言的预录语音。选择 Off 后仍可继续编辑声音选择器。

- Control Panel 仅在实际溢出时滚动。状态面板、Working 指示器和粉色 KIMI KRINIK 机器人运行在官方引擎上。Action Menu 显示版本与构建号。

- 历史恢复不会出现空白帧，延迟到达的请求准备错误不会删除无关轮次。内部指令不会显示为助手文本。

## 验证

候选版本有 607 项检查通过、1 项跳过，typecheck 和 lint 全部通过，六个目标包均通过静态与 import 验证。Build 18 通过了隔离 VS Code 中的追加消息、历史恢复、媒体、上下文阈值和置顶请求场景。主配置文件已收到真实的 70% 上下文警告。

其余聊天修复路径在主配置文件上的验收仍在进行。

## 安装

下载 `kimi-code-win32-x64.vsix`，选择 **Extensions → ⋯ → Install from VSIX…**。KIMI KRINIK 可与官方 Kimi Code 和 KIMI FORK 并存，项目与会话保持不变。返回官方扩展不会删除它们。
