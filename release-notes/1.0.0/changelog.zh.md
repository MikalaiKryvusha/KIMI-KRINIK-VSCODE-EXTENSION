# KIMI KRINIK 1.0.0

2026-11-27

KIMI KRINIK 1.0.0 帮助你管理长时间的智能体会话、可靠地追加消息，并在需要回应时及时收到提醒，同时保留官方 Kimi Code 2.7.2 引擎。

## 新增内容

✅ 表示扩展中已有。

| 功能 | Kimi Code | KIMI FORK | KIMI KRINIK |
|---|---|---|---|
| 引擎 | 官方 2.7.2 | 较旧的 2.2.0 | ✅ 官方 2.7.2，跟随上游更新 |
| 自动压缩控制 | — | — | ✅ 可关闭自动压缩，包括正在进行的操作；手动 `/compact` 仍可使用 |
| 上下文窗口控制 | — | — | ✅ 配置阈值、提前收到提醒，并在新聊天中继续讨论而不丢失脉络 |

| 消息送达与队列恢复 | 普通队列 | 强制 steering 可能重复或跳过消息 | ✅ 每条消息仅显示一次并只送达一次；被拒绝的消息回到原位置 |

| 模型与推理强度 | — | — | ✅ 在同一选择器中搜索和收藏；保留明确选择，恢复的会话保留自己的强度 |
| Control Panel 与通用设置 | 固定面板和 VS Code 设置 | 固定面板和 VS Code 设置 | ✅ 隐藏按钮时保留功能，可调整顺序，并使用一个本地化设置窗口 |

## 验证

扩展有 682 项检查通过、1 项跳过，typecheck 和 lint 全部通过。隔离安装通过实测帧与截图验证了聊天可见性、steering 完成、历史恢复、声音设置与各对话框。六个平台专用 VSIX 与平台无关的 `kimi-code-universal.vsix` 均已打包并通过静态检查。win32-x64 与 universal 包均已在新的 Extension Host 中通过启动验证。
