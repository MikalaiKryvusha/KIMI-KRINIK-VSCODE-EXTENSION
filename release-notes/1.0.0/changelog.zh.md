# KIMI KRINIK 1.0.0

2026-11-27

KIMI KRINIK 1.0.0 帮助你掌控长时间的智能体工作、追加消息而不丢失，并使用三语言界面；同时保留官方 Kimi Code 2.7.2 引擎与 KIMI FORK 界面。

## 新功能

- 可关闭自动压缩，包括正在进行的操作。手动 `/compact` 仍可使用。

- 当对话接近上下文上限时，KIMI KRINIK 会提前提醒，并帮助你在新聊天中继续讨论而不丢失脉络。

- 在智能体工作时继续输入：追加消息及附件立即显示并只送达一次；需要排队时，消息按顺序等待，被拒绝的消息回到原位置。

- 置顶栏显示最后一条完全滚出屏幕的用户消息：仍在屏幕上的消息不会重复进入置顶栏。置顶栏在出现、消失和替换时均有平滑动画；展开与折叠时，消息气泡和外部容器以同步的 200 ms 动画运动。居中的箭头在现有查看器中展开全文与媒体。

- 图片、视频和纯媒体消息提供可点击缩略图，恢复历史后使用同一查看器。手动换行和空行原样保留，用户气泡左侧显示本地化的发送时间。

- 每条助手文本回复下方都有独立的 Copy 和 Fork 按钮：每次复制仅包含相邻文本。

- 通过本地化描述找到合适的 Skill，选择后可立即使用或排队等待。

- 次级模型按钮在大尺寸下显示「子智能体」文字，紧凑形式保持纯机器人图标。

- Control Panel 状态提示使用全大写 ON/OFF：ON 略带绿色，OFF 略带红色。通用设置在全部三种语言中分行显示各状态。

- 声音事件设为 Off 时其区域变暗，但选择器仍可用。每个事件可设置声音与音量，并提供三种语言的预录语音。

- 模型与推理强度通过一个选择器设置，支持搜索和收藏。MAX/XHigh 选择会持久保存，恢复的会话保留自己的强度。

- English、Русский 和 中文 可在对话框中切换，当前语言始终排在首位。

- Control Panel 仅在实际溢出时滚动。状态面板、Working 指示器和粉色 KIMI KRINIK 机器人运行在官方引擎上。左侧 Activity Bar 使用粗轮廓机器人图标，带顶部切角和与内置标志相同位置的方形眼睛。Action Menu 显示版本与构建号。

- 历史恢复不会出现空白帧，延迟到达的请求准备错误不会删除无关轮次。内部指令在实时聊天和历史恢复中均不会显示为助手文本。

- 追加消息后，每条助手回复都保持可见且顺序正确。回答完成后 Working 状态消失，重新打开历史时同样的消息仍被保留。

- 一眼看出哪些聊天按钮可以点击：添加文件或媒体、历史记录、设置齿轮、发送消息、停止 AI 智能体、会话、创建新聊天和浮动滚动到底部按钮均显示指针光标。所有八个按钮均在安装的 VSIX 上通过真实鼠标悬停与点击验收。

## 验证

扩展有 682 项检查通过、1 项跳过，typecheck 和 lint 全部通过。隔离安装通过实测帧与截图验证了聊天可见性、steering 完成、历史恢复、按钮光标、声音设置与各对话框。六个平台专用 VSIX 与平台无关的 `kimi-code-universal.vsix` 均已打包并通过静态检查。win32-x64 与 universal 包均已在新的 Extension Host 中通过启动验证。
