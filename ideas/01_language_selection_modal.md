## Вектор цели

**Achieve.** В Action Menu одна кнопка `Language / 语言 / Язык` открывает отдельное окно выбора языка, чтобы меню занимало меньше места, а привычное переключение и сохранение языка продолжало работать.

**Maintain.** Порядок English → Русский → 中文, отметка текущего языка, мгновенная смена интерфейса и запись выбора через существующий `changeLanguage` остаются неизменными.

**Avoid.** Дублирования списка языков одновременно в меню и окне, потери выбора при ошибке сохранения и появления второго независимого состояния языка.

## Критерии приёмки

1. В открытом Action Menu есть одна кнопка языка, а не три отдельных пункта English, Русский и 中文.
2. Кнопка Action Menu показывает только локализованное `Language` / `Язык` / `语言` по текущему языку интерфейса. При клике меню закрывается, а отдельное Dialog-окно показывает три варианта и отмечает текущий. Заголовок окна и его список используют один порядок: выбранный язык первый, затем English, Русский и 中文; из двух невыбранных English всегда идёт перед Русским. Примеры: `Русский / English / 中文`, `中文 / English / Русский`.
   [OWNER] «в этой строке и в кнопке так же, пожалуйста, отображай выбранный язык на первом месте. Вторвм по силе всегда или русский или английский, английский сильнее русского» · 2026-11-24 (чат)
   [OWNER] «Кнопка в меню должна быть Язык», «в меню динамическая кнопка Язык на трех языках» · 2026-11-24 (чат)
3. Выбор варианта вызывает существующий `changeLanguage`, сразу меняет интерфейс и сохраняется через `updateExtensionSetting`; окно остаётся рабочим для смены обратно.
4. При закрытии окна выбранный язык сохраняется; ошибка сохранения использует существующий rollback `settings.store`.
5. Компонентный тест подтверждает пункты 1–4, а установленный VSIX показывает меню и окно на русском и английском без горизонтального overflow.

## Риски и границы

- Не менять общий VS Code setting `kimi.language`, его rollback или порядок языков.
- Не создавать второй store: окно использует `extensionConfig.language` и `changeLanguage` из существующего settings store.
- Не переносить другие секции Action Menu и не менять звуковое/Control Panel окна.
- Узкие панели проверяются по фактической ширине Dialog, а не только по классам.
