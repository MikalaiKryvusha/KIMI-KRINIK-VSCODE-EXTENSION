## Вектор цели

**Achieve.** В Action Menu одна кнопка с тремя переводами слова «язык» через `/` открывает отдельное окно выбора языка. Перевод текущего языка интерфейса стоит первым: `Language / Язык / 语言`, `Язык / Language / 语言` или `语言 / Language / Язык`.

**Maintain.** Порядок English → Русский → 中文, отметка текущего языка, мгновенная смена интерфейса и запись выбора через существующий `changeLanguage` остаются неизменными.

**Avoid.** Дублирования списка языков одновременно в меню и окне, потери выбора при ошибке сохранения и появления второго независимого состояния языка.

## Критерии приёмки

1. В открытом Action Menu есть одна кнопка языка, а не три отдельных пункта English, Русский и 中文.
2. Кнопка Action Menu одновременно показывает все три перевода слова «язык» через `/`. Перевод текущего языка интерфейса стоит первым, остальные сохраняют порядок English → Русский → 中文: English — `Language / Язык / 语言`; Русский — `Язык / Language / 语言`; 中文 — `语言 / Language / Язык`. При клике меню закрывается, а отдельное Dialog-окно показывает три варианта и отмечает текущий. Заголовок окна и его список используют один порядок: выбранный язык первый, затем English, Русский и 中文; из двух невыбранных English всегда идёт перед Русским. Примеры: `Русский / English / 中文`, `中文 / English / Русский`.
